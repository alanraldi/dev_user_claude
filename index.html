A constante que conecta o círculo ao infinito

Rotação 0°
Distância 0
π × d ≈ 0

Relação fundamental

C = π × d  =  2πr

Ao rolar sobre uma linha plana, um círculo percorre exatamente π × diâmetro em uma volta completa (360°). O ponto vermelho traça uma cicloide — a curva que prova geometricamente o valor de π ≈ 3.14159...
